# Wireframes globaux

```text
+--------------------------------------------------------------------------------+
| Projet | Enregistrer | Annuler/Rétablir | Lecture | Tempo | Rendu | Aide       |
+----------+-------------------------------+------------------------+------------+
| Bibliothèque / pistes | Arrangement        | Inspecteur             | Transport  |
| - Projet              | règle / grille     | onglet Son             | 00:00.000  |
| - Instruments         | clips et scènes    | onglet Événements      | boucle     |
| - Effets              | automation         | onglet Mixage          | métronome  |
| - Rendus              |                   |                        |            |
+----------+-------------------------------+------------------------+------------+
| Console: pistes, mute, solo, armement, gain, pan, envois, master              |
+--------------------------------------------------------------------------------+
```

| Zone | Rôle | Navigation clavier |
|---|---|---|
| Barre globale | projet, annulation, lecture, tempo, rendu, aide | Tab puis Entrée/Espace |
| Bibliothèque | ressources et pistes | flèches, Entrée pour ouvrir |
| Arrangement | clips, grille, automation | flèches pour sélectionner, Entrée pour éditer |
| Inspecteur | paramètres du contexte sélectionné | Tab, libellés associés aux champs |
| Console | mixage, état des pistes, master | Tab, flèches sur curseurs |
| Modale | confirmation et erreurs bloquantes | focus piégé, Échap ferme |

Les raccourcis globaux sont désactivés pendant l'édition de texte : `Ctrl/Cmd+S` enregistre, `Espace` lecture/pause, `Ctrl/Cmd+Z` annule, `Ctrl/Cmd+Shift+Z` rétablit et `?` ouvre l'aide.
